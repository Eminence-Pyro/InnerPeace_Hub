# InnerPeace Hub — Blog Website Project Plan

## Project Overview

This project involves building a blog website for **InnerPeace Hub**, owned by **Ezinne Uduma**, a content creator who currently publishes podcast episodes on Spotify. The goal is to create a central content hub that complements her podcast and improves discoverability, branding, and audience engagement.

---

## Brand & Content Direction

**Brand Name:** InnerPeace Hub
**Owner:** Ezinne Uduma

**Content Focus:**

* Relationship guidance (healthy relationships, communication, boundaries)
* Healing from heartbreak and emotional resilience
* Faith-based living and spiritual growth (drawing closer to God)
* Godly parenting principles and family life
* Personal growth, inner peace, and purpose

**Tone & Voice:**

* Empathetic, calm, and reflective
* Practical, guidance-oriented
* Faith-centered (where appropriate)

**Assets:**

* Logo: Available (to be incorporated in Navbar and Footer)
* Founder Image: Optional (recommended for About page and Hero/featured sections)

---

## Objectives

* Create a professional blog website
* Convert podcast episodes into written blog posts
* Embed Spotify podcast episodes into the site
* Improve visibility through SEO and structured content
* Build a platform that is easy to maintain for a non-technical user

---

## Project Approach

### Development Strategy

* Use plain HTML, CSS, and JavaScript
* Build a static, responsive website
* Structure content using reusable components (where possible)
* Prepare for future scalability (CMS or backend integration if needed)

---

## Website Structure

### Pages

* Home Page
* Blog Page (list of posts)
* Single Post Page
* Podcast Page
* About Page
* Contact Page

---

## Core Features

* Display blog posts
* Embed Spotify podcast episodes
* Responsive design (mobile-first)
* Clean and professional UI

---

## Content Strategy

* Each podcast episode will have a corresponding blog post
* Blog posts will include:

  * Title
  * Summary
  * Key points
  * Embedded Spotify player

---

## Technical Structure

### File Structure

```
/index.html
/blog.html
/post.html
/podcast.html
/about.html
/contact.html
/styles.css
/script.js
/data/posts.json
```

### Data Handling

* Use a JSON file to store blog post data
* Dynamically render content using JavaScript

---

## Spotify Integration

* Use Spotify embed iframe for podcast episodes
* Place embeds within blog posts and/or podcast page

---

## Design Guidelines

* Minimalist and clean layout
* Consistent color palette (2–3 colors)
* Clear typography hierarchy
* Mobile-first responsive design

---

## Deployment Plan

* Develop locally
* Push code to GitHub repository
* Deploy using Netlify or Vercel

---

## Future Enhancements
